Eight background-transparent RGBA PNGs include four blank-display devices, two sleds, and two mounting backplates.
Four OpenRaster (.ora) documents pair each housing with six screen layers in the correct positions. Open a document in Krita or GIMP. In the Layers panel, hide the current screen and show the desired one. Hide all screen layers for the blank device. Export the visible layers as a transparent PNG for compositing.
The compact and long housings represent the three-cell and six-cell versions of the concept.
